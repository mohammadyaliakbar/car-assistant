# شبیه‌ساز دستیار هوشمند خودرو

شبیه‌ساز بدون خودرو و بدون OBD، سناریوهای رانندگی و خرابی را از **همان مسیر داده‌ی پروژه** عبور می‌دهد:

```
داده‌ی خام OBD ← DataValidator ← VehicleRecord(source="SIMULATOR")
              ← Detectorهای واقعی ← RoadsideEmergencyService ← داشبورد
```

هیچ رویدادی مستقیم ساخته نمی‌شود؛ آستانه‌های Detectorها دست‌نخورده‌اند.

## اجرا

```bash
python tools/run_dashboard.py          # داشبورد: http://127.0.0.1:8765/
python tools/lab_report.py             # بدون مرورگر: جدول نتیجه‌ی هر ۸ سناریو
python -m pytest                       # تست‌ها (تست مرورگر بدون Chromium خودکار skip می‌شود)
```

برای نقشه‌ی کامل هنگام ارائه، یک‌بار قبل از آن با اینترنت داشبورد را باز کنید (کاشی‌ها از اینترنت می‌آیند؛ بدون اینترنت مسیر و خودرو روی پس‌زمینه‌ی تیره دیده می‌شوند).

## سناریوها و منبع تشخیص

| سناریو | تشخیص |
|---|---|
| رانندگی عادی | هیچ رویدادی انتظار نمی‌رود |
| خاموشی موتور در بزرگراه | `StoppageDetector` + دستیار اضطراری |
| داغ‌شدن مایع خنک‌کننده | `CoolantOverheatDetector` (هشدار ← بحرانی) |
| افت ولتاژ باتری | `VoltageDetector` |
| کد خطای ECU | `TroubleCodeDetector` |
| قطع GPS | **Detector ندارد**؛ فقط وضعیت داشبورد |
| چند خرابی هم‌زمان | سه Detector؛ هشدارها بدون تناقض ادغام می‌شوند |
| تغییر شرایط مسیر | بدون رویداد؛ شهری ← بزرگراه ← خارج شهر |

## تاریخچه، بازپخش و گزارش

- هر اجرا (کامل، متوقف‌شده یا نیمه‌کاره) خودکار در `data/lab_history/` ذخیره می‌شود (حداکثر ۲۰۰ اجرا).
- «بازپخش» همان فریم‌های ذخیره‌شده را به‌ترتیب زمانی پخش می‌کند؛ داده‌ی تازه‌ای تولید نمی‌شود و تلگرام هرگز در بازپخش فعال نیست.
- صفحه‌ی گزارش: `/report.html`. خروجی CSV: `/api/report.csv` (هر اجرا) و `/api/report.csv?by=scenario`.
- «تشخیص‌نشدن» و میانگین تأخیر فقط از اجراهای **کامل‌شده** حساب می‌شود.

## تلگرام

پیش‌فرض خاموش. فقط اگر `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` در `.env` باشد، تیک داشبورد فعال می‌شود؛ پیام‌ها با `[SIMULATION]` شروع می‌شوند.

## محدودیت‌ها

- مختصات مسیرها تقریبی‌اند، نه هندسه‌ی دقیق جاده.
- اطلاعات جاده به‌صورت پیش‌فرض ساختگی (برچسب‌خورده) است؛ `RoadAnalyzer` پروژه فقط با `data/roads_tehran.sqlite` قابل انتخاب است.
- `StoppageDetector` فقط وقتی فعال می‌شود که موتور در سرعت حداقل ۱۰ km/h خاموش شود.
- توصیه‌های اضطراری راهنمای شبیه‌سازی‌اند و جایگزین دستورالعمل رسمی امداد جاده‌ای نیستند.
